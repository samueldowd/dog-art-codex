# Implemented architecture

`settings.py` parses the explicit app TOML and allowlisted dotenv. Build metadata is absent from startup. `contracts.py` defines immutable event, crop/observation, description/feature, decision, recipe, collage and publication records. `serialization.py` persists explicit UTC source timestamps and immutable crop hashes. `diagnostics.py` reports redacted readiness; live probes are read-only and doctor never spends.

`storage.py` initializes versioned local SQLite with WAL/foreign keys and refuses incompatible/unversioned unknown databases. Short BEGIN IMMEDIATE transactions serialize event uniqueness, queue claim/lease tokens, identity comparisons/enrollment, request reservations and daily state changes. Backup uses SQLite's supported online backup API. Media/model/API/network work is outside DB transactions.

`frigate/` implements verified0.18 read-only auth modes, filtering, byte/deadline limits, durable polling cursor/pagination and incomplete-event refresh. MQTT-shaped envelopes can feed the same ingestor; polling is the selected production route. `vision/` provides FFmpeg/FFprobe bounded native decode, timestamp-matched snapshot geometry, native recording frames, per-frame local YOLOX boxes and crop ranking/association. Ambiguous/occluded/clipped evidence stays review. Frigate path anchors choose detector search areas, never replace fresh boxes.

`description/` verifies the exact Ollama tag/digest/capabilities before/after structured image requests and preserves unknown/conflicting facts. `identity/` hashes/version-pins genuine ONNX image features, compares multi-view galleries with calibrated thresholds/separation, serializes enrollment and preserves reversible correction audit. Shadow mode and missing calibration never auto-enroll. Full-body evidence needs auditable reviewed/calibrated visibility; original payloads remain intact.

`budget.py` and `portraits/` use canonical-dog/style uniqueness, persistent reservations, build-scope plus ongoing caps, a shared paid-operation barrier, SDK retries0 and explicit uncertain states. Crash before submission is recovered under exclusive paid ownership; possible submissions become indeterminate. Saved output is not accepted until PNG/alpha plus actual visual review. A returning dog's changed description cannot change the uniqueness key.

`daily/` owns event-date membership, persistent generation/revision, startup/midnight catch-up and immutable local archives. A file/thread lock serializes rollover, current revision finalization and publication. `collage/` preserves silhouettes/aspect/colors with seeded non-overlapping scattered placement; capacity/missing input fails without silently omitting members. `publishing/` isolates SMB in a killable worker with one total deadline, verifies staged/final hashes/images, safely replaces only the owned image and reconciles possible prior success. Last-moment wall-date/generation/revision validation rejects stale work.

`runtime.py` orchestrates these adapters and durable jobs. Source, local model, portrait and publication outages remain stage-specific. Rollover runs independently. CLI/service/timer paths are explicit. No new frontend, cloud captioning, detector replacement or HA redesign is part of the implementation. See CONTRACTS.md for worker ownership and interface seams; original docs04/06 remain the required behavior/evidence contract.

The outbox also has `reset_pending`: immutable empty revision0 for the current wall day/generation, with priority until the first verified publication. It is independent of desired composition membership, so a pre-timer sighting cannot obsolete the reset while art is pending. Guards allow only that exact reset and reject later full publication until its receipt; once verified, blank0 can repeat only while it is still the exact empty desired revision. Prior nonempty revisions and prior generations remain stale. Same-day missing art is an explicit composition dependency; calendar reconciliation succeeds and preserves all membership. Existing schema1 supports the additional state without destructive migration.
